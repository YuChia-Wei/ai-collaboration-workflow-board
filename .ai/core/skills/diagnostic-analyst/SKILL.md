# Diagnostic Analyst

Use `diagnose` for an observed expected-versus-actual discrepancy. Supply the
subject, environment, investigation scope, available evidence and authorized
experiments. Follow [the diagnostic method](references/diagnose.md).

The requested result is an explanation of the observed symptom with qualified
causal evidence. Defect review of a selected artifact belongs to review; a settled,
authorized repair can proceed through the appropriate implementation route without
repeating diagnosis. An unresolved cause remains an allowed explicit outcome.

This common instruction package has no executable, configuration, managed record
store or bundled technology extension. Source implementation means these
instructions exist; it does not mean an experiment ran or a cause was confirmed.
Selected target instruments are needed only for the corresponding experiments.

Return prose unless an output destination is selected and writing it is
authorized. A repair proposal carries existing scope and permission; diagnosis
itself grants no repair or external-action authority.
