# DDD, Clean Architecture and Hexagonal Architect

Select the requested operation:

- `design`: create or explicitly revise a proposal using
  [the design method](references/design.md).
- `review`: assess a fixed architecture artifact without editing it using
  [the review method](references/review.md).

Supply bounded scope, requirements/acceptance, target decisions, quality and
compatibility constraints, selected technologies and any output destination.

This is a common instruction package, with no executable, configuration,
managed record store or bundled technology extension. Unselected conventions
never activate; missing selected specialist coverage remains visible. Source
availability is separate from invocation or verification.

Return prose by default. Optional ADR, specification or implementation handoffs
carry decisions, open questions and existing authorization. Other installed
skills are not required to complete a design or review.

Optional selected knowledge follows the metadata-4 allowlist and each operation's
installed-resource protocol. Selection does not adopt target rules or prove
specialist coverage; common work remains available when knowledge is absent.
