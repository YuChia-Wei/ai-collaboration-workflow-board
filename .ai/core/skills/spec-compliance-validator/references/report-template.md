# Scoped compliance report outline

This is an ordinary prose reference, not a persisted machine schema/template or
a requirement to create a repository workflow. Fill only observed facts. Mark
missing values unavailable; do not prefill success or fictional commands.

## Selection and bindings

- Requested instruction operation(s), selected scope and nonempty required scope.
- Artifact family/version/logical ID, exact raw digest and actual reader identity.
- Owner operation/result and evidence reference; public structure contract/digest.
- Normative source paths/URIs, revisions/digests/locators and actual authority.
- Code/test/config/dependency commit or explicit content identities.
- Explicit profile/version, observed SDK/runtime/runner/environment/provider.
- Actual command/argv, working directory, observation time, exit/outcome and
  accessible evidence; distinguish supplied observation from execution here.
- Exclusions, target decision/rationale and representation/legacy loss notes.

## Separate stage findings

| Stage | Actual outcome | Evidence | Missing prerequisites and limitations |
| --- | --- | --- | --- |
| Authoring | Supplied/proposed/unknown | Sources and draft | Approval/uncertainty |

| Semantics | Findings and unresolved intent | Criterion/source/code locators | Scope/completeness limits |
| Runtime | Observed per-criterion evidence or unavailable/deferred | Actual runs | Required level/environment gaps |

## Complete evidence matrix

| Criterion ID and exact text | Origin and authority | Applicability / exclusion decision | Required evidence level | Implementation location | Assertion location | Run / evidence reference | Result | Limitation |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Fill every selected condition and expanded component | Exact source | Target rationale | Actual required level | Exact location or unavailable | Exact location or unavailable | Genuine observation or unavailable | satisfied / contradicted / unavailable / deferred / excluded | Specific gap |

Account for every owner inventory statement/scenario/assertion, then explain all
expanded components. Retain inferred/unresolved IDs, open questions, missing
sources, skipped runs and failing observations. Counts are by row state, never
an invented universal percentage. Record total required scope separately from
exclusions and unselected scope.

## Conclusion and next action

Apply contradiction -> not-compliant first; otherwise missing required evidence
or empty required scope -> unavailable; only complete required coverage ->
compliant-within-scope. State exact subjects, versions, scope, observed environment,
remaining uncertainty and exclusions. Assign each missing/deferred obligation an
owner/next action when known. Keep authoring, structural, semantic and runtime
outcomes distinct. A changed subject requires fresh binding/reuse evidence.
